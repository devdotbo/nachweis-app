# Check-in draft, 2026-09-08

Paste-ready. Every status below was checked on disk on 2026-09-07 unless marked "in progress". Under 200 words.

Project name: Nachweis

Description: Nachweis helps token issuers accept EUDI identity evidence and apply their approval to customers' linked crypto wallets, without putting identity documents on chain.

Built so far: Foundry contracts on the way to Sepolia: an attestation registry with a pluggable proof verifier interface, a transfer-restricted demo fund token, a subscription contract and an SP1 proof adapter verified against the Sepolia SP1 gateway on a fork; 87 passing Foundry tests. Landing page. Blind-relay branch of our verifier service (client-side encryption key, server relays unopened): in progress. SP1 zkVM proving spike for the SD-JWT PID statement: proof produced and verified locally on a laptop, Groth16 wrap matching the Sepolia SP1 gateway version.

Next: phone run of the registered request from the official German test wallet (sample identity) to the verifier; Uniswap v4 permissioned pool allowlist checker reading the registry; front end (issuer approval screen, investor doors, revoke); decision between client-side and server-side proving.

Blockers: our question on Privy prize eligibility for Continuity entries (asked 2026-09-01) is still unanswered. [Note added 2026-09-09: this sentence was wrong; the builder states the question was never sent. Kept as the historical draft. See wiki/track-decision.md.]

Team: one builder.

Track: Continuity. Pre-existing work disclosed: the builder's own EUDI verifier (Rust), a verifier front end and an Android holder app; all event work is in new repositories with full git history.


Update 2026-09-07 late: two proof routes exist (SP1 server-side, verified by the real SP1 gateway on a Sepolia fork; Noir client-side, proven on the Mac, the Android emulator and the iOS simulator against one VK), a blind-relay mode in the verifier so the server never sees the presentation, a bridge service, a front end, a laptop companion and two phone prover apps. Nothing deployed yet; the phone run with the official test wallet is next.

# Work packages

Work packages replace day lanes because the builder works in parallel (decision 2026-09-07). Status values: pending, running, green, red, dropped. A package is green only when its acceptance test passed and the evidence (log, tx hash, screenshot, test output) is on disk. Only green packages enter the video (/Users/bioharz/git/ethglobal/nachweis/wiki/submission-checklist.md).

Evidence repair of 2026-09-08 (WP19, from the review in /Users/bioharz/git/ethglobal/nachweis/wiki/handoff-fable-2026-09-08.md): the status column keeps the schema values, and a separate column splits the evidence into four classes. L = local implementation on the builder's Mac (tests, emulator, simulator, local Sepolia fork). W = official-wallet run (the official German test wallet with a sample identity presenting to this verifier). D = physical-device run (iPhone or Pixel). S = deployment to Sepolia with a broadcast transaction. A class reads "green" only when a run record is on disk; otherwise "unverified" or "pending (builder)".

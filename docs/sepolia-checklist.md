# Sepolia checklist (builder)

What the builder provides before `scripts/sepolia-deploy.sh` and `scripts/browser-real-wallet-up.sh --deployment` run on Sepolia. One line each, in the order the scripts need them. Values go into the gitignored `.env` at the repository root (copy `.env.example`); nothing here is printed by the scripts. The numbers come from the dry run of 2026-09-10 (`docs/deployments/sepolia-dry-run-2026-09-10.md`).

1. `SEPOLIA_RPC_URL`, required. Any Sepolia JSON-RPC endpoint that accepts `eth_sendRawTransaction`. Known to work with the fork scripts: `https://ethereum-sepolia-rpc.publicnode.com` (the default fork source of `pool-local.sh`, `browser-real-wallet-up.sh --pool` and `sepolia-deploy.sh --dry-run`; forked at head 2026-09-10 without errors). No archive node is needed: anvil forks at the head block and the deploy script only sends transactions. For the real broadcast a private endpoint (Alchemy, Infura, QuickNode, dRPC) is recommended because the public one rate-limits `--slow` polling; unverified which of them the builder has.
2. `DEPLOYER_PRIVATE_KEY`, required, plus Sepolia ETH on it. Measured deployer gas for registry, FundToken, Subscription, HonkVerifier, NoirPidVerifier, MockStable, checker, adapter, pool and liquidity: 14,180,393 gas. At 2 gwei that is 0.028 ETH, at 20 gwei 0.284 ETH; with a 1.5 margin fund 0.043 ETH (2 gwei) to 0.425 ETH (20 gwei). Fund 0.5 Sepolia ETH to cover the investor top-up (0.02 ETH) and the bridge's `attestWithProof` transactions (operator key = this key; their gas is not measured here) at 20 gwei. Use a throwaway wallet: `browser-real-wallet-up.sh --deployment` hands this key to the local Vite page as the Issuer's operator dev key (`VITE_DEV_OPERATOR_KEY`) and to the bridge as `OPERATOR_PRIVATE_KEY`.
3. `INVESTOR_PRIVATE_KEY`, required for the browser stack on Sepolia (`browser-real-wallet-up.sh --deployment` refuses to start without it): the page's investor dev signer; it pays for subscribe, the mUSD faucet mint, the Permit2 approval and the swap (about 0.45 M gas measured, under 0.01 ETH at 20 gwei). Set `INVESTOR_ADDRESS=<its address>` too, then `sepolia-deploy.sh` step 5 sends it `INVESTOR_FUND_ETH` (default 0.02) from the deployer when it holds less. Optional for `sepolia-deploy.sh --probe` on Sepolia (the probe subscribes and swaps with this key).
4. `ETHERSCAN_API_KEY`, optional. With it, `sepolia-deploy.sh` step 6 runs `forge verify-contract --guess-constructor-args` for every contract our scripts created (registry, FundToken, Subscription, HonkVerifier, NoirPidVerifier, MockStable, checker); the adapter is Uniswap's factory output. Verification is not exercised by the dry run; a failed verification is reported in the record, never fatal.
5. Tunnel for the relay verifier, required for the phone flow, no account and no token: `scripts/g0-up.sh` starts a cloudflared quick tunnel (`cloudflared tunnel --url`, installed via Homebrew; anonymous `*.trycloudflare.com` hostname, DNS takes up to `TUNNEL_WAIT_SECS`, default 180 s). Alternatives: `TUNNEL=ngrok` (needs the ngrok authtoken configured on the machine, outside this repository; unverified in this work package) or `TUNNEL=none PUBLIC_URL=https://…/` for a reverse proxy the builder runs. Unchanged between the fork run and the Sepolia run.
6. Privy, optional, only if the builder decides to show the standing order on Sepolia (`docs/privy-standing-order.md` section 7). `automation/.env` (read by `automation/src/config.ts`): `AUTOMATION_SIGNER=privy`, `PRIVY_APP_ID`, `PRIVY_APP_SECRET`, `PRIVY_AUTHORIZATION_KEY`, `PRIVY_SIGNER_ID`, plus `CHAIN_ID`, `RPC_URL`, `REGISTRY`, `SUBSCRIPTION`, `FUND_TOKEN`, `START_BLOCK` (the record prints these six), optional `POLICY_ID`, `POLL_MS`, `PLAN_INTERVAL_SECS`, `PORT`. App side: `VITE_PRIVY_APP_ID`, `VITE_PRIVY_SIGNER_ID`, `VITE_AUTOMATION_URL`. The embedded wallet needs about 0.05 Sepolia ETH from the deployer (no gas sponsorship credits).
7. Everything else the scripts read, all optional with defaults: `PID_ISSUER_KEY_HASH` (default: the sandbox PID issuer pin `0xb4f2bfa1…e079` from `scripts/browser-real-wallet-up.sh`, the official German test wallet; only override for another issuer), `POLICY_ID`, `REQUIRED_BITS`, `POOL_FEE`, `TICK_SPACING`, `FUND_LIQUIDITY`, `STABLE_LIQUIDITY`, `DEMO_AMOUNT`, `OPERATOR_ADDRESS`, `LP_PRIVATE_KEY`, `HONK_VERIFIER` (reuse an already deployed HonkVerifier), `SWAP_AMOUNT_IN` (probe). For the browser stack as before: the verifier worktree with its built binary and `fixtures/live` (`VERIFIER_DIR`, default `/Users/bioharz/git/ethglobal/nachweis-verifier-relay`), `BRIDGE_ISSUER_TOKEN` (fresh random if unset), and the phone with the official test wallet holding the sandbox PID.

Not needed: an SP1 verifier deployment (the video uses the Noir route; `DeploySp1Verifier.s.sol` stays in the manual table of `docs/demo-runbook.md` section 9), a faucet contract (the app mints mUSD from `MockStable` itself), an archive RPC.
